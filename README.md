# One Remote

One web app to control Bluetooth LED lights that normally need separate apps:

- **Lotus Lantern X / duoCo** lights (ELK-BLEDOM family)
- **Hello Fairy** string lights (Hysiry)
- **Govee** Bluetooth strips and bulbs

Uses Web Bluetooth. On iPhone, open it in the **Bluefy** browser; on Android/desktop use Chrome or Edge.
Close the official apps first, since each light accepts only one connection.
